# 共创工作室 · 整合站

一个入口、一套 UI：**首页 / 导航 / 下载 / 食谱 / 游戏 / Minecraft**，纯静态，直接丢到 GitHub Pages 就能访问。

- **首页** —— 工作室主界面
- **导航** —— 33 个非搜索引擎的实用站点，按分类、翻页浏览，自动匹配电脑 / 手机
- **下载** —— Minecraft 光影下载
- **食谱** —— 小鲨鱼菜谱（完整 SPA，顶部品牌条 + 底部固定操作栏）
- **游戏** —— 固定式街机厅：开机动画、屏幕内 14 款卡带（含东方《妖妖梦》网页版）
- **Minecraft** —— 欢迎页 / 工作室介绍 / 服务器介绍，各占一屏

顶部是浏览器 / 资源管理器风格的外壳：**前进、后退、刷新 + 地址栏面包屑 + 分区标签**。
分区可以在「设置 ⚙」里调整顺序，也可以用「显示分区」开关隐藏不常用的分区（首页与 Minecraft 固定显示）。
底部是常驻窄条页脚（电脑 52px、手机 44px），带工作室交流群。

> 页面只保留必要的操作信息，不再出现分区编号标题、演示账号明文和营销式长句。

## 一、部署到 GitHub Pages

1. 把本目录里的**全部文件**上传到仓库根目录：
   `index.html`、`css/`、`js/`、`assets/`、`apps/`、`archive/`、`README.md`、`.nojekyll`
2. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`，保存。
3. 等 1～2 分钟，访问 `https://你的用户名.github.io/`。

- `.nojekyll` 必须一起上传。
- 所有路径都是相对路径，放在仓库根目录或子目录都能正常打开。

### 本地预览

```bash
python -m http.server 8080
# 或
npx serve .
```

打开 `http://localhost:8080/`。食谱与街机都用 iframe 加载，**必须用 http:// 打开**；直接双击 `index.html`（`file://`）会导致子页面资源加载失败。

## 四、街机厅（游戏分区）

### 1. 固定式舞台

进入「游戏」分区后页面不再上下滚动，街机铺满可用高度：

- **桌面**：保留网站顶栏和底栏，街机屏占满内容区，尽量做大。
- **手机**：进入分区自动隐藏网站顶栏 / 底栏，做沉浸式占满全屏；左上角「✕ 退出」返回首页。
- 街机屏内部自己滚动，不影响页面本身。

### 2. 开机流程

1. 待机：屏幕中央一个大电源键（呼吸光）+ `PRESS POWER`。
2. 点击电源：约 1.8 秒开机动画（CRT 亮线展开 → 扫描 → ARCADE 标志）。
3. 进入大厅：14 张卡带在屏幕里，桌面 4 列、手机 2 列，支持分类、搜索、最高分。
4. 点卡带：游戏 iframe 启动，覆盖屏幕。
5. 「⏻ 关机」回待机；游戏内「返回」/ `Esc` 回大厅，「⛶ 全屏」可放大。

### 3. 14 款卡带

- **东方（1）**：東方妖々夢 · TH07 Web 复刻（完整原作资源、WASD/空格、BGM 开关、本地存档）
- **街机（6）**：贪吃蛇、俄罗斯方块、打砖块、太空侵略者、乒乓球 Pong、像素鸟
- **益智（5）**：2048、扫雷、记忆翻牌、数字华容道、连连看
- **对弈（2）**：五子棋、井字棋

东方网页版的操作：方向键移动、`Z` 射击、`X` 炸弹、`C` 结界、`Shift` 低速、`P` 暂停、`F` 全屏；手机拖拽 + 底部「炸弹 / 结界 / 低速」按钮。
最高分存在 `localStorage` 的 `mg_scores`，东方详细存档在 `touhou_save_v1`。

### 4. 新增小游戏

1. 在 `apps/arcade/index.html` 里仿照现有 `register({ id, name, icon, tags, mount })` 添加游戏；
2. 在 `js/data.js` 的 `arcade.games` 补一条同 id 的卡带；
3. 新分类要同时改 `data.js` 的 `arcade.categories` 和 `apps/arcade/index.html` 的 `CATS`。

## 五、导航

### 1. 展示规则

- 导航卡片与下载卡同宽同高（桌面 3 列、每页 6 个；手机 2 列、每页 6 个），33 个站点简介扩写到 4 行。
- 右上角分类筛选：全部 / 视频 / AI / 工具 / 学习 / 社区 / 资源 / 办公 / 生活。
- 搜索框在左上，底部翻页，每页 12 个。
- **按设备过滤**：每个站点带 `devices` 标记；手机只显示手机可用的，电脑只显示电脑可用的。

### 2. 改站点

数据都在 `js/nav.js`：

```js
{
  id: "runoob",
  name: "菜鸟教程",
  badge: "菜",
  accent: "#2ECC71",
  cat: "study",
  devices: ["pc", "mobile"], // 电脑 / 手机可用
  desc: "编程入门教程与在线示例。",
  url: "https://www.runoob.com/"
}
```

分类在 `window.NAV_CATS` 里增删；新增站点直接往 `window.NAV_SITES` 里加一条，保存刷新即可。
`devices` 只写 `["pc"]` 的站点手机端不会出现，只写 `["mobile"]` 的电脑端不会出现。

## 七、食谱

### 1. 界面

- 顶部两行：第一行 logo + 「小鲨鱼菜谱」，搜索框在标题正下方常驻（管理员界面）。
- 左下角常驻操作栏：通知中心 / 主题色 / 浅色模式 / 退出登录；桌面在侧边栏左下竖排，手机固定在底部横排。
- 内容区底部留出避让空间，不会被固定栏挡住。

### 2. 隐私

- 登录、注册页显示「账户与密码仅保存在本机浏览器，不会上传到服务器」。
- 界面里不再显示初始管理员明文账号和密码；需要初始账号时查看 `apps/recipe/js/store.js` 的种子逻辑，首次登录后请立即修改密码。
- 密码用 Web Crypto 哈希后存在 `localStorage`，纯前端站点不适合真正的多用户生产环境。

### 3. 恢复 / 隐藏食谱分区

食谱入口默认显示。想隐藏可在「设置 ⚙ → 显示分区」里关闭；也可以编辑 `js/data.js` 注释掉 `{ id: "recipe" ... }`，同时把 `index.html` 的食谱 `<section>` 注释掉。
`apps/recipe/` 目录始终原样保留。

## 八、搜索与下载

- 点顶部面包屑直接在地址栏里搜全站：分区、网站、游戏、下载都能搜到，点空白处恢复面包屑。
- 底部「PCL2 下载」会先把密码复制到剪贴板并提示「密码已复制」，1.8 秒后自动打开蓝奏云；密码不在页面上显示。
- 查看服务器地址的弹窗只能用「确定」关闭；点空白会让确定按钮闪一下提醒，地址本身和「复制地址」都能复制。

## 九、设置

- **显示分区**：首页、Minecraft 固定显示；导航、下载、食谱、游戏可以关掉。关掉后只在顶栏、手机抽屉和排序列表里隐藏，直接输入地址仍可访问。
- **自定义分区顺序**：拖动或点 ↑↓ 调整，保存后固定。
- 设置存在浏览器本地：
  - 分区顺序 `gx.site.order.v1`
  - 隐藏分区 `gx.site.hidden.v1`

## 十一、小提示

- 页面标题字体来自 Google Fonts，访问慢可以删掉 `index.html` 里的字体 `<link>`，会自动回退系统字体。
- 外链都在新标签页打开，第三方内容不由本站控制。
- 食谱数据、游戏最高分、分区设置都存在浏览器本地，换设备或清缓存会回到初始状态。
- 手机浏览器的地址栏网页无法隐藏，只能做到隐藏本站顶栏 / 底栏。
