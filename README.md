# 共创工作室 · 整合站

把原来分散在 `/2/`、`/3/`、`/5/`、`recipe/`、`Download-site/` 五个项目里的内容，合成了一个站点：
**一个入口、一套 UI**，电脑和手机自动适配，纯静态，直接丢到 GitHub Pages 就能访问。

- 首页 —— 原 r2「共创工作室」主界面
- 导航 —— 原 r5「快捷整合站」的常用站点卡片
- 下载 —— 原 Download-site 的光影下载
- Minecraft —— 原 r3 的 Minecraft 专站
- ~~食谱~~ —— 原 recipe「小鲨鱼菜谱」，**入口已隐藏（代码全部保留，只是整段注释掉了）**，恢复方法见文末

顶部是浏览器 / 资源管理器风格的外壳：**前进、后退、刷新 + 地址栏面包屑 + 分区标签**。
面包屑会记录你本次会话访问过的分区（例如 `站点 › 首页 › 导航 › 下载`），点任意一段就能直接切回去。
底部是常驻的窄条页脚（电脑 52px、手机 44px），不会挡住内容。
分区标签的顺序可以在「设置 ⚙」里自定义，保存后固定，刷新也不丢。

## 一、怎么部署到 GitHub Pages

1. 把本目录里的**全部文件**上传到你的仓库根目录（`lyueyue-max.github.io`）：
   `index.html`、`css/`、`js/`、`assets/`、`apps/`、`archive/`、`README.md`、`.nojekyll`
2. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`，保存。
3. 等 1～2 分钟，访问 `https://你的用户名.github.io/`。

几个细节：

- `.nojekyll` 必须一起上传，否则 GitHub 会忽略以 `_` 开头的文件。
- 所有路径都是**相对路径**，放在仓库根目录或子目录（如 `/site/`）都能正常打开。
- 原来的 `/2/`、`/3/`、`/5/` 目录可以直接删掉，站点已经不再依赖它们。

### 本地预览

在站点目录里执行任意一个：

```bash
python -m http.server 8080
# 或
npx serve .
```

然后打开 `http://localhost:8080`。

## 二、背景图在哪替换（你最关心的）

**只需要换一个文件：**

```
assets/bg-main.jpg      ← 换掉它，全站背景立即生效
```

建议尺寸 1920×1080，JPG 压缩到 300KB 以内。图上会自动盖一层奶油色薄纱（保证文字可读），所以随便放风景图、渐变图都不会糊字。

想调薄纱浓度或换成别的图，改一个地方就够：

```css
/* css/style.css 第 44 行 */
--bg-image: url("../assets/bg-main.jpg");
```

同一个文件里的第 85 行是背景图层实际使用这个变量的位置。
主界面的头像 / 工作室 logo 则是 `assets/avatar.jpg`（替换后首页和 Minecraft 分区一起更新）。

## 四、日常怎么改

**加一个导航卡片**：在 `index.html` 里搜 `分区二：导航`，照着已有的 `<article class="link-card">` 复制一份，
改 `--accent`（卡片主色）、首字徽标、标题、简介、链接即可。搜索框会自动识别新卡片。

**加一个下载卡片**：搜 `分区三：下载`，复制一份 `<article class="dl-card">`，改标题、简介、适配版本和下载链接。

**改分区名称 / 默认顺序**：`js/data.js` 里的 `sections` 数组，`name` 改名、数组顺序就是默认顺序。
（访客自己在设置里调过的顺序存在浏览器 localStorage，不会影响你这份文件。）

**改配色**：`css/style.css` 开头的 `:root`，品牌蓝 `--blue`、黄 `--yellow`、红 `--red`、奶油底 `--cream`。

**调顶栏 / 底栏高度**：同一个 `:root` 里 `--header-h`（电脑 96 / 手机 52）和 `--footer-h`（电脑 52 / 手机 44），
改完所有高度（食谱窗口、Minecraft 首屏等）会跟着变，不用一处处改。

**导航排序怎么调**：右上角 ⚙ → 设置 → 「自定义分区顺序」。可以拖动，也可以点 ↑ ↓，保存后顺序固定；
排序入口平时不在顶栏出现，只放在设置里。

## 五、这次合并做了什么

- **内容全部保留**：五个项目的文案、卡片、链接、图片、QQ 群号都搬过来了，一条没删。
- **看板娘已移除**（按你的要求），也不再引入任何懒加载动画脚本。
- **旧路径废弃**：不再有 `/3/`、`/5/` 这种分散入口，全部收进这一个站点。
- **样式统一**：原来五个项目各写一套 `body` 全局样式，现在统一到一套设计变量（奶油底 + 蓝黄红三色 + 宋体标题）。
- **手机适配**：断点 768px。手机上顶栏收成一行，分区标签收进左上角 ☰ 抽屉，卡片单列，表格改为堆叠；不是两套代码，是一套 CSS 自动切换。
- **布局收紧**：区块上下留白、标题与内容间距整体压缩；页脚改为常驻窄条，不再随页面滚走。
- **面包屑带记忆**：按访问顺序记录最近 6 个分区（手机显示最近 2 个），点一下即可回切，刷新后仍保留。
- **食谱应用**：它是带登录、增删改查、localStorage 的完整 SPA，整页搬进 `apps/recipe/`，用嵌入式框架加载，
  功能、路由、数据都保持原样，不和其他分区抢页面状态。「新窗口打开」收进了窗口右下角的悬浮按钮，
  登录页底部那句「演示站点数据存在 localStorage」的提示已按你的要求删除。
  另外按你的要求调整了动画时机：**切换页面**时保留入场动画（整页淡入 + 卡片浮现），
  **点击展开下拉菜单**、点击当前页菜单项、页面内局部操作都不再触发动画；
  手机点击不再出现高亮闪烁，表单字号改为 16px 避免 iOS 点输入框时自动放大。
  **当前入口已隐藏**：`index.html` 里食谱分区整段被 HTML 注释包住，`js/data.js` 里 recipe 那一项也被 `//` 注释，
  所以顶部标签、面包屑、手机抽屉都不再出现食谱；文件本身一个没删。
- **清理**：
  - 删掉了 r2 里指向不存在字体的 `@font-face`、失效的滚动倾斜脚本引用、重复的 `placeholder.jpg`；
  - 删掉了 r3 里没用到的 `0000.png`、`2.png`、`3.png`、`5.png`、5MB 的 `devfolio.gif` 等大文件；
  - 原项目里**被注释隐藏的代码没有删**，全部原样保存在 `archive/原始注释代码.html`，复制出来就能还原。
- **`.nojekyll` + 相对路径**：GitHub Pages 开箱即用。

## 六、小提示

- 页面标题的衬线字体来自 Google Fonts（`index.html` 里有那一行 `<link>`）。如果访问慢，可以整行删掉，
  会自动回退到系统宋体，功能不受影响。
- 下载和导航里的外链都是 `target="_blank"`，在新标签页打开，不会打断当前分区。
- 食谱应用的数据存在**浏览器 localStorage**，换设备 / 清缓存会回到初始状态，这是原项目本来的设计。

## 七、恢复 / 再次隐藏食谱入口

隐藏只是加注释，文件一个都没删。**恢复只要两步：**

1. `index.html` 里搜 `分区四：食谱`，把包住整个 `<section>` 的最外层注释去掉
   （删掉开头那段说明所在的注释标记，以及结尾 `食谱分区结束` 前的注释标记）；
2. `js/data.js` 里把这一行前面的 `//` 去掉：

   ```js
   // { id: "recipe", name: "食谱", accent: "#F59E0B" },
   ```

保存后刷新，顶部标签、面包屑、手机抽屉里就会重新出现「食谱」，点开就是原来的小鲨鱼菜谱。

想再隐藏就反过来：把这两处重新注释掉即可，`apps/recipe/` 目录始终原样保留，
直接访问 `apps/recipe/index.html` 也仍然能单独打开菜谱应用。
